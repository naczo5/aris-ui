Widgets

All widgets are free functions taking the context first. They require an active panel (BeginPanel/EndPanel) because layout belongs to the Yoga tree. Every widget draws and handles input in the same call.


#include "ui/widgets/widgets.hpp"

API

FunctionSignatureBehavior
Buttonbool Button(Context&, const char* label)Returns true on the frame the click completes (press + release inside).
Togglevoid Toggle(Context&, const char* label, bool* value)Flips *value when clicked; knob position eases via valueT.
Slidervoid Slider(Context&, const char* label, float* value, float minValue, float maxValue)Updates *value while dragged; shows a right-aligned value label.
Labelvoid Label(Context&, const char* text, Color color = {}, float fontSize = 0.f)Static text; fontSize = 0 uses the theme default.

Visual states

Colors and shadows ease through WidgetStateStore — buttons lift on hover (hoverT) and settle when pressed (pressT), toggles slide their knob with valueT. The states are frame-rate independent (exponential smoothing), so animations look identical at 60 or 240 fps.

StateFillShadow
idleaccentopacity 0.18, offset (0,2)
hoveraccentHoveropacity 0.32, offset (0,5)
pressaccentActiveopacity 0.08, offset (0,2)

You can inspect a widget's eased state yourself via ctx.theme() + WidgetStateStore if you build custom controls.

Custom widgets

Custom controls are just immediate-mode code using the primitives:


void ColorDot(ui::Context& ctx, ui::Color color) {
    ui::WidgetFrame w = ctx.BeginWidget("dot", 20.f);
    if (w.rect.Valid()) {
        ui::RectStyle st;
        st.fill = color;
        st.cornerRadii = ui::Vec4(10.f);
        ctx.DrawRect(w.rect, st);
    }
    ctx.EndWidget();
}

BeginWidget(label, height) creates a full-width flexbox row of the given height inside the current panel and returns a frame with rect (valid from the previous frame's layout) and state (the retained WidgetState).

Theming

Everything visual is a token in ui::Theme (see include/ui/core/theme.hpp). Set a custom theme with ctx.SetTheme(theme) before the first frame.
